# Campus Bites - Campus Cafeteria

A small informational website for the UCP campus cafeteria, built by a five-member team for DevOps Fundamentals (SEST4663), Assignment 01.

## Pages
- `src/index.html` - Home (Muhammad Faizan)
- `src/menu.html` - Menu (Ali Imtiaz)
- `src/deals.html` - Daily Deals (Muhammad Abdullah)
- `src/order.html` - How to Order (Hafiz Muhammad)
- `src/feedback.html` - Feedback & Contact (Nimrah)

Shared styles live in `styles/style.css`. Open any page in `src/` in a browser; no build step is needed.

## Workflow
feature branch -> pull request into `develop` (2 approvals) -> `release/v1.0` -> pull request into `main` (3 approvals).
